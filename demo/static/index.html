ONE-TIME SETUP

Prepare your measurement engine.

The interface is ready. Install the package and download the model weights to measure images.

uv pip install -e ".[web]"
.venv/bin/python -m demo.download_models

Run these commands from the repository root, then refresh the runtime. The checkpoints are large; you only need to download them once.
